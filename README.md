# ACTIVIDAD 1: INTRODUCCIÓN AL HTML, CSS Y JS.
HTML (Lenguaje de Marcado de Hipertexto) es el lenguaje fundamental utilizado para crear todas las páginas web. No se trata de un lenguaje de programación, sino de un lenguaje de marcado que tiene como propósito definir la estructura y el contenido de un sitio: textos, imágenes, enlaces y botones.

Opera a través de etiquetas (que están encerradas entre signos de mayor y menor que) que abren y cierran bloques para señalar al navegador qué representa cada elemento:

| **Elemento** | **Para qué sirve** |
| --- | --- |
| `<!DOCTYPE html>` | Le dice al navegador que es HTML5 |
| `<html lang="en">` | Raíz del documento, define el idioma |
| `<head>` | Contiene metadatos (no se muestra en pantalla) |
| `<meta charset="UTF-8">` | Soporte de caracteres especiales (ñ, acentos) |
| `<meta name="viewport">` | Hace que funcione bien en celulares |
| `<body>` | Contenido visible de la página |
| `<p>` | Párrafo de texto |


En la actual actividad sobre la cual estamos trabajando, se nos enseño lo basico del lenguaje html, a utilizar etiquetas para poner titulos, parrafos, cambiarle de colores a las cosas, asi como darles alguna animación.
Los codigos css y js, son la forma de incomporar ya sea diseños o estilos de forma externa.
